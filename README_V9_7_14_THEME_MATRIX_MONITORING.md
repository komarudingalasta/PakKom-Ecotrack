# PakKom EcoTrack v9.7.14 — Monitoring Semua Tugas per Tema

- Monitoring utama kini dimulai dari Tema lalu Kelas.
- Satu matriks menampilkan siswa sebagai baris dan seluruh tugas dalam tema sebagai kolom.
- Status tiap sel: Periksa, Belum, Draf, Perbaikan, atau nilai yang sudah diberikan.
- Klik sel pengumpulan membuka drawer penilaian tanpa meninggalkan matriks.
- Setelah nilai disimpan, matriks diperbarui langsung.
- Tugas kelompok dipetakan ke setiap anggota kelompok, tetapi tetap menggunakan satu submission kelompok yang sama.
- Pencarian siswa dan filter status tersedia.
- Nama siswa dan header tugas sticky; matriks dapat digeser vertikal/horizontal.
- Monitoring per tugas lama tetap dipertahankan sebagai opsi sekunder.
- Tidak ada perubahan Firestore Rules dari v9.7.13/v9.7.11.
