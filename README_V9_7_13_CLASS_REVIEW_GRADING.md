# PakKom EcoTrack v9.7.13 — Monitoring & Penilaian Per Kelas

Perubahan utama:
- Monitoring tugas langsung berupa daftar siswa/kelompok per kelas.
- Admin dapat berpindah kelas tanpa menutup monitoring; Wali otomatis kelasnya sendiri.
- Ringkasan status: total, perlu diperiksa, belum/draf, perlu perbaikan, sudah dinilai.
- Filter cepat Semua / Periksa / Belum / Perbaikan / Dinilai.
- Klik siswa/kelompok membuka jawaban dan form nilai pada panel yang sama.
- Simpan nilai tidak menutup monitoring dan daftar langsung diperbarui.
- Tugas kelompok ditampilkan satu baris per kelompok dengan daftar anggota.
- Pengumpulan yang perlu perbaikan tetap dapat dilihat, tetapi menunggu kirim ulang sebelum dinilai.
- Desktop/tablet memakai dua panel; mobile membuka detail dari daftar dan dapat kembali ke daftar.
- Firestore Rules tidak berubah dari v9.7.12/v9.7.11.
