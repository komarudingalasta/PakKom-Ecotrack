# PakKom EcoTrack v9.3 – Revision Workflow

- Wali melihat status `Belum Diperbaiki` setelah memilih Perlu Perbaikan.
- Selama status revision, tombol Periksa diganti `Menunggu siswa`.
- Setelah siswa Kumpulkan Ulang, status kembali menjadi `submitted` dan di Wali tampil `Periksa`.
- Status siswa tetap `Perlu Perbaikan` sampai dikumpulkan ulang.
- Tulisan versi dihilangkan dari Portal Siswa dan Tugas Saya. Versi tetap ditampilkan pada halaman Tugas Admin/Wali.
- Firestore Rules tidak berubah dari v9.2.
