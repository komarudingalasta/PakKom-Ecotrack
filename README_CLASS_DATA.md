# Data Kelas Saya — Wali Kelas

## Akses
- Wali Kelas: hanya halaman kelas walinya pada UI.
- Admin: dapat memilih kelas.
- Guru biasa: menu tidak ditampilkan.
- Halaman bersifat pemantauan/read-only; tidak mengedit pendataan dari sini.

## Harian
- Pilih tanggal pendataan.
- Daftar seluruh siswa aktif.
- Status Wadah dan Tumbler per siswa.
- Filter: Semua, Lengkap, Tidak Bawa Wadah, Tidak Bawa Tumbler, Tidak Bawa Keduanya.
- Ringkasan jumlah/persentase siswa hadir.
- Klik siswa untuk melihat riwayat.

## Analisis
- Pilih rentang tanggal.
- Persentase Wadah, Tumbler, dan Keduanya.
- Tren membaik / stabil / menurun berdasarkan perbandingan paruh awal dan paruh akhir periode.
- Analisis setiap siswa:
  - Sangat Konsisten >=90%
  - Konsisten >=75%
  - Mulai Konsisten >=50%
  - Perlu Diingatkan <50%
- Bagian Perlu Diingatkan hanya memasukkan siswa dengan minimal 2 hari hadir agar tidak menyimpulkan dari data terlalu sedikit.

## Privasi
- Data individu tidak dibagikan otomatis ke EcoChat.
- EcoChat sebaiknya hanya menerima ringkasan kelas.
