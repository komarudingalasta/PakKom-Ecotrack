# Periode Analisis
Status tanggal: Terjadwal -> Berjalan -> Selesai.
Setelah selesai: snapshot -> review Admin -> bagikan ke wali kelas -> arsip.
Publikasi hasil terpisah dari status periode; Admin dapat tarik akses tanpa menghapus snapshot.
Koreksi hasil final harus melalui Buka Koreksi -> perbaiki/reset -> Hitung Ulang -> Kunci, dan setiap tindakan dicatat ke auditLogs.
