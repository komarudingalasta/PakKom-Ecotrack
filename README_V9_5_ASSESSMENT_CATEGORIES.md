# PakKom EcoTrack — Penilaian & Kategori

Rentang nilai otomatis:
- 0–69: Perlu Bimbingan
- 70–79: Berkembang
- 80–89: Cakap
- 90–100: Mahir

Kategori dihitung dari nilai saat ditampilkan dan tidak disimpan sebagai field terpisah.
Wali/Admin melihat rentang nilai saat memeriksa dan kategori otomatis saat mengetik nilai.
Siswa melihat nilai dan kategori setelah status Sudah Dinilai.
Jika tugas dikembalikan untuk perbaikan, nilai dikosongkan sampai hasil revisi dinilai kembali.

Firestore Rules tidak berubah dari v9.2/v9.4.
