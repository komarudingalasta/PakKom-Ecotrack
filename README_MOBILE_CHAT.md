# EcoChat Mobile Polish

Perbaikan utama:
- HP selalu membuka daftar grup terlebih dahulu.
- Grup tidak lagi langsung menghilang karena grup pertama auto-selected.
- Setelah pilih grup, chat tampil layar penuh.
- Tombol kembali mengembalikan ke daftar grup.
- Daftar grup menampilkan nama grup, cuplikan pesan terakhir, badge unread, dan chevron.
- Desktop/tablet tetap bisa membuka grup pertama otomatis.
- Resize dari HP ke desktop / sebaliknya dirender ulang secara aman.
