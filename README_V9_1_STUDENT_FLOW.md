# PakKom EcoTrack v9.1 — Student Assignment Flow

Fokus versi ini hanya alur Admin -> Siswa untuk tugas individu.

## Yang diuji
1. Admin membuat dan menerbitkan tugas untuk kelas tertentu.
2. Siswa login melalui /siswa/.
3. Menu Tugas membuka /siswa/tugas/.
4. Halaman membaca assignments dengan array-contains classId siswa.
5. Tugas dikelompokkan berdasarkan status.
6. Siswa dapat menyimpan draf dan mengumpulkan jawaban teks/link.
7. Submission disimpan ke taskSubmissions.

Tugas kelompok sengaja belum diaktifkan untuk pengumpulan pada v9.1.
