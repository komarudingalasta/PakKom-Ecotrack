# PakKom EcoTrack v9 — Separate Task App

Tugas dipisahkan dari main.js.

- Admin/Wali: `/tugas/`
- Siswa: `/siswa/tugas/`
- Firebase project, Auth, Firestore, siswa, dan kelas tetap sama.
- v9.0 tahap awal memprioritaskan alur tugas individu: Admin buat -> siswa lihat -> siswa kirim link/teks -> Wali/Admin periksa -> nilai/revisi.
- Tugas kelompok ditampilkan tetapi pengumpulan kelompok ditunda sampai alur individu lolos uji.
